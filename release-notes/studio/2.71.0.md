本版把会话里提到的文件真正接进界面：回复中交付的图片直接画出来，写成子目录的路径也能打开，中途插话可以带图片。侧边栏按项目重新分组，新会话不再自动归入某个项目，选中的文件夹本身就是项目。安装包版本号、本地打包产物过期和关闭最后一个会话后的界面一并修好。

## 新增

- 回复里交付的图片画在文件行上方，点开进共用缩放器；不是图片或加载失败时只留文件行 (71b6564)
- 会话里写成子目录的路径（`target/release/app.exe` 这类）能打开，不再报文件已不在原处 (71b6564)
- 中途插话可以带图片，图和那句话在同一个消息里送达 (1df207f)
- 选中的文件夹就是项目，名称只改变侧边栏里的显示，磁盘上的文件夹名不动 (797f92f)
- 新建会话不归属任何项目，项目在任务有了之后再从药丸里选 (ff2ab1b)
- 发布页只放安装包和手机应用，CLI 归档不再混在里面 (435f8f0)

## 变更

- 侧边栏按项目重新分组：行序服从列表自身的顺序，工作区内按时间分桶，折叠和拖拽都能跨重载存活 (dbaebff)
- 手机配对以新凭据判定，不再被任意一个旧凭据放行 (74b4655)

## 移除

- peer 信箱整套移除：会话之间互发消息的机制、它的设置面与视图，项目改由侧边栏和打开文件夹抵达 (dbaebff)

## 修复

- 关闭最后一个会话后回到房间，不再留一张空卡片 (cef36c9)
- 添加项目时不填名称，事后也能给它起一个 (7433760)
- 重复添加同一个文件夹不会把它改名 (ecfa620)
- 项目药丸保住自己的名字，菜单去掉多余的移动步骤 (e93249a)
- 任务运行的加号不再继承当前项目 (5232bd6)
- 安装包终于带上被要求的版本号 (613872f)
- pnpm 传进来的裸 `--` 不再吃掉安装包的版本号 (b246bb3)
- 本地打包先构建要发出去的 SPA，不再把上一次的旧产物打进去 (33f257e)
- 按后缀找文件有了边界：条目和深度都有上限，超了就说路径太宽泛，请求取消即刻停 (c55bbdb)
- 拼错的路径只开一个标签页，不再留下一个打不开的 (14e90c3)
- 带图片的插话被拒绝时状态回到队列，不会因为一张图暂停整条队列 (a75be43)
- 第二次本地打包复用已有的驱动和已解包的 Electron，不再重复下载 (7cffc0c)
- 产物构建前的架构检查补上了实现，注释不再声称一件没做的事 (800fec3)

<!-- lang:en -->

Files a conversation names now reach the interface: a delivered picture is drawn in the reply, a path spelled from a subdirectory still opens, and mid-turn guidance can carry a picture. The sidebar groups by project, and the folder you pick is the project.

## New

- A picture a reply presents is drawn above its file row and opens the shared viewer; a file that is not a picture, or one that will not load, keeps the row alone (71b6564)
- A path written against a subdirectory (`target/release/app.exe`) opens where it really lives instead of being reported gone (71b6564)
- Mid-turn guidance can carry a picture, delivered on the same message as the words (1df207f)
- The folder you pick is the project; a name changes only what the sidebar shows, not the folder on disk (797f92f)
- A new conversation belongs to no project until one is chosen from the pill (ff2ab1b)
- The release page carries the installer and the phone app, not the CLI archives (435f8f0)

## Changed

- The sidebar groups by project: rows follow the list's own order, a workspace buckets by time, and every fold and drag survives a reload (dbaebff)
- A phone pairing is judged by a new credential rather than by any credential already held (74b4655)

## Removed

- Peer mail is gone: the mailbox between sessions, its settings surface and its views. A project is reached from the sidebar and by opening its folder (dbaebff)

## Fixed

- Closing the last conversation leaves the room rather than an empty card (cef36c9)
- A project added without a name can be given one afterwards (7433760)
- Adding the same folder twice does not rename it (ecfa620)
- The project pill keeps its name, and the menu sheds its move steps (e93249a)
- A task run's plus stops inheriting the current project (5232bd6)
- The installer carries the version it was told (613872f)
- pnpm's bare `--` no longer costs every installer its version (b246bb3)
- A local package builds the SPA it is about to ship (33f257e)
- The suffix search is bounded by entry and depth budgets, and stops when the request is cancelled (c55bbdb)
- A misspelled path opens one tab instead of leaving a failed one behind (14e90c3)
- A picture-carrying steer that is refused goes back to the queue instead of pausing it (a75be43)
- A second local build reuses the driver and unpacked Electron it already has (7cffc0c)
- The dist check reads the architecture it always claimed to check (800fec3)
