本版有两件大事。一是手机端应用随本仓库首次正式发布（1.0.0），扫码即可在手机上使用 Studio；二是「手机访问」拆成了两扇独立的门，同一台机器上的局域网手机和反向代理隧道可以同时连进来，配对码按门签发。此外打开长会话明显变快，会话框新增对话轮次显示，工作台版面回到更省地方的一栏形态，并移除了登录、云备份、插件市场与社区。

## 新增

- **手机端（1.0.0）** — 手机端应用随本仓库正式发布，版本 1.0.0：手机只绘制界面，通过本机的回环代理连到这台电脑上的内核 (0b87f7e)
- 手机端与桌面端同版本发布，手机端安装包与桌面端安装包一同提供下载 (0b87f7e)

- **手机访问与反向代理** — 手机访问支持反向代理：`[serve] public_origin` 说出反代的名字，手机从那里进来，局域网地址同时保留 (f84b09e)
- 配了反代时，手机的门与反代的门同时打开：一个接在局域网地址上，同一个端口在回环再开一个，各自带自己的门禁 (c27905b)
- 手机卡片不再放开关，改为显示两扇门——局域网地址与反代地址；地址、配对码与二维码都跟着当前那扇门 (516d0ef)
- 手机卡片改为从上到下读：二维码、有效期、换一个码的按钮 (3c74271)
- 「复制链接」复制的是配对链接而不是裸地址：裸地址只能让已配对的浏览器进入，新浏览器会停在「这台设备未配对」 (516d0ef)
- 反代地址保存失败时，面板会说明原因，而不是默默不动 (3e6e568)
- 手机面板会显示反代地址，并说明它在下次开门时生效 (ccae2f9)

- **会话框与启动画面** — 会话框下方的计量条新增「对话轮次」，显示这个会话由人主动开启了多少轮 (3abbd18)
- 启动画面与图标是本仓库自己的：跟随主题的安静启动页，以及黑色方块配白色字形的标记 (fae0b55)
- 启动器居中显示，并去掉上方「在工作台打开」那一行标题 (45f21d9)

- **工作台** — 工作台的分支芯片能读取并切换「项目文件夹」下面的具名仓库 (72bbbf7)
- 分支切换会指明它移动的是哪一个仓库 (4206264)
- 输入框把当前仓库交给分支芯片，不再向工作区根目录发问 (995d46a)
- 文件树会画出只从文件路径推断出的文件夹 (6d359bf)
- 标签条末尾的「+n」改为只读数、不点击的计数，并新增「关闭左侧标签」 (844f3a9)
- 一轮结束时显示它开始的时间和跑完用了多久 (b5c8643)

## 变更

- **工作台版面** — 停靠时工作台是一列而不是一张卡片：它延伸到窗口栏，标签条挂到窗口栏上，与对话之间只隔一条细线 (04c4481)
- 标签条新增到达任意已打开标签的入口，溢出菜单同样改为浮层，避免被窗口栏裁掉或吃掉拖动窗口的按下 (04c4481)
- 标签选择器用对勾和底色标出当前行，不再用左侧竖条 (04c4481)
- 工作台版面回到 2.58 的形态：画布是主体，文件树是右侧自适应宽度的一列，停靠时两者轮流占同一列，不再出现「列表旁边一栏空画布」(be94c64)
- 同时移除文件树列的手动拖宽，以及为此写下的那批测试 (be94c64)
- 项目列表在冷启动时默认全部折叠，折叠状态不再写进 localStorage、不再跨启动继承 (45e0f5d)

## 修复

- **会话打开与读取** — 打开长会话改为从最新的完整快照开始重放，跳过被整体替换的旧快照：实测 109 MB 的会话从 2.33 秒降到 0.43 秒，7040 条消息与从头重放完全相同 (2984609)
- 打开会话不再把整份日志读两遍：第一次为弄清智能体构成而读的内容，在大小与修改时间未变时直接复用 (2984609)
- 打开会话先读它记录的模型再装配运行时，不再先用默认模型装配一遍、发现不一致再装配第二遍 (5693231)

- **手机配对** — 手机代理同时携带 WebView 与内存两个 cookie jar 的凭据，不再因为挑中空的而让内核回「未配对」 (b012c6a)
- 只有能发码的门才会被请求配对码：本机没有可拨地址时自动走反代门，设置页不再停在一条走不通的路上 (f7a452f)
- 二维码不会被迟到的旧响应覆盖；同一扇门连续两次请求时，屏上留下的是最后请求的那一枚 (f7a452f)
- 两扇门组成的标签条可以用方向键切换，焦点可见，并且不再与外层对话框共用同一个无障碍名称 (f7a452f)
- 只有当前那扇标签取得抬起的底面色：React 把 `aria-selected={false}` 写成字符串 `"false"`，裸属性选择器会把两个都点亮 (f7a452f)
- 剪贴板上的配对链接不再消耗屏幕上那张二维码，两者是各自独立的凭据 (56cd566)
- 已配对设备会记录最近一次从哪扇门进来，面板不再猜「同一个 Wi-Fi」 (56cd566)

- **来源与门禁** — 反代把 Origin 的 authority 一并改写时，仍被认作反代的门，而不是当作陌生来源拒绝 (4fb7608)
- 收紧到 TLS 的来源校验改为比较真实端口，`http://host`(80) 与 `https://host`(443) 不再被折成同一个门 (56cd566)
- 加载页面取字体时不再被记为「没有携带设备凭据」的警告，那条提示重新只说真正的拒绝 (56cd566)
- 本地门开在回环上时不再发出手机拨不通的配对链接，与「没配反代却要反代码」一样按名字拒绝 (56cd566)
- 配了反代但它的门没能绑上时，面板会说明原因，而不是让「名字已生效」和「没有这扇门」同时成立 (56cd566)
- 「通道名不存在」(400) 与「本机没有这扇门」(409) 改用两个错误码，提示语各自对应 (56cd566)

- **界面与其他** — 浏览器标签按页面的标题命名：加载完成后读一次标题，跨文档跳转时丢掉旧名，不再让每个标签都显示成 `https://…` (788e10c)
- 提交与推送按钮打开的是卡片而非对话框，名字随之去掉省略号 (969ec90)
- 最小化、最大化、关闭三个图标统一到同一尺寸，不再三个大小不一 (25759cc)
- 窗口按钮与停止图标按同一度量绘制，整组不再比旁边松而重 (fdf267a)
- 冒烟测试使用自己的临时 home，不再抢占正在运行的 Studio 的数据锁 (173c38c)
- 更新检查的嵌套路径挂在发布主机下，而不是发布前缀下 (c3bae8a)

## 移除

- 移除登录、云备份、插件市场与社区：没有这些功能后账号无事可做，相关页面、样式、支付二维码、链接表与文案一并移除 (4a4c842)
- 移除「从任何地方访问」的中继区块：这一版本没有登录来支撑它，而说明一条走不通的路比不说明更糟 (3c74271)
- 移除视图切换上的计数与启动器的最近文件列表，绘制它们的样式与文案一并移除 (712e863)

## 升级须知

- 手机端是独立应用（1.0.0），需要单独安装；它通过回环代理连到本机的内核，不是在浏览器里打开一个网址 (0b87f7e)
- 一台同时有局域网和反向代理的机器，现在两扇门会同时打开。配对码按门签发，换一扇门要重新扫码 (c27905b)
- 选择分享地址时不再列出 `127.0.0.1`：那是反代在本机拨的门，手机拨不通它 (516d0ef)
- 工作台版面对齐 2.58：文件树不再可以拖动改宽，停靠时与画布轮流占同一列 (be94c64)
- 项目列表不再记住上一次展开过哪些项目，每次冷启动都是折叠的 (45e0f5d)
- 本版移除了登录、云备份、插件市场与社区，这些入口连同其数据不再出现 (4a4c842)

<!-- lang:en -->

This release ships the Android app (1.0.0), gives phone access two doors with a pairing code per door, opens long sessions faster, counts turns in the composer, restores the one-column dock layout, and removes sign-in, cloud backup, the plugin market and the community.

## New

- **The phone app (1.0.0)** — The Android app ships from this repository as version 1.0.0: the phone draws the interface and reaches the kernel on this machine through its own loopback proxy (0b87f7e)
- The app releases alongside Studio, and its package downloads beside the installer (0b87f7e)

- **Phone access and reverse proxies** — Phone access understands a reverse proxy: `[serve] public_origin` names it, phones arrive through that name, and the LAN address keeps working beside it (f84b09e)
- With a proxy named, the phone's door and the proxy's door open together — one on the LAN address and the same port on loopback, each behind its own gate (c27905b)
- The phone card no longer carries the switch. It shows the two doors a code can point at, and the address, the code and the picture follow whichever is on screen (516d0ef)
- The phone card reads top to bottom now: the picture, how long it lasts, and the one button that asks for another (3c74271)
- "Copy link" hands over a pairing link rather than the bare address: an address alone stops a browser that has not paired at "this device is not paired" (516d0ef)
- A reverse proxy address the kernel refuses to save now says so instead of silently staying put (3e6e568)
- The phone panel shows the reverse proxy's address and says that it lands the next time the door opens (ccae2f9)

- **The composer and the boot screen** — The meter under the composer gains "Turns", showing how many turns a person opened in this session (3abbd18)
- The boot screen and the app mark are this repository's own: a quiet boot screen that follows the theme, and a black tile with a white glyph (fae0b55)
- The launcher is centred, and the "Open in the workbench" heading above its entries is gone (45f21d9)

- **Workbench** — The workbench's branch chip reads and switches the named repository inside a folder of projects (72bbbf7)
- A branch switch names which repository it moves (4206264)
- The composer hands the branch chip the repository it speaks for, instead of asking the workspace root (995d46a)
- The file tree draws every folder the listing implies, including ones known only from a file's path (6d359bf)
- The "+n" at the end of the tab strip is a count to read rather than a button to press, and "close tabs to the left" joins it (844f3a9)
- A finished turn shows when it started and how long it ran (b5c8643)

## Changed

- **The workbench layout** — Docked, the workbench is a column rather than a card: it runs to the window bar, its strip is portalled onto that bar, and one hairline separates it from the conversation (04c4481)
- The strip gains a way to any open tab, and the overflow menu becomes a floating layer so the bar cannot clip it or take the presses meant for dragging the window (04c4481)
- The tab picker marks the row on screen with a tick and a wash rather than a leading bar (04c4481)
- The workbench returns to 2.58's shape: the canvas is the body, the tree is a self-sizing column on the right, and docked the two take turns in one column — no more empty canvas column beside the list (be94c64)
- The tree column's manual resize goes with it, along with the tests that pinned it (be94c64)
- The project list starts fully folded on a cold launch, and fold state is no longer written to localStorage or carried between launches (45e0f5d)

## Fixed

- **Opening and reading a session** — Opening a long session replays from the newest full snapshot, skipping the snapshots wholly replaced since: a measured 109 MB session went from 2.33 s to 0.43 s, with all 7040 messages identical to a replay from byte 0 (2984609)
- Opening a session no longer reads the whole log twice: what the first read learned about its agent composition is reused while the file's size and modification time still match (2984609)
- Opening a session reads the model it was left on before assembling a runtime, instead of assembling on the default model and assembling a second one when the two differ (5693231)

- **Phone pairing** — The phone's proxy carries the credential from either cookie jar, instead of picking the empty one and being answered "not paired" (b012c6a)
- Only a door that can actually issue a code is asked for one: a machine with no reachable adapter falls back to the proxy's door instead of leaving the settings page with no way forward (f7a452f)
- A late answer no longer replaces the code on screen, and two asks on one door leave the last one asked for (f7a452f)
- The two-door tab strip answers the arrow keys, shows where focus is, and no longer shares its accessible name with the dialog around it (f7a452f)
- Only the tab that names the door on screen takes the raised surface: React writes `aria-selected={false}` as the string `"false"`, so the bare attribute lit both (f7a452f)
- A pairing link on the clipboard no longer spends the symbol on screen; the two are independent credentials (56cd566)
- A paired device records the door it last came through, so the panel stops guessing "the same Wi-Fi" (56cd566)

- **Origins and gates** — A proxy that rewrites the Origin's authority along with the Host is still the proxy, rather than a stranger's page being refused (4fb7608)
- Tightening an origin to TLS compares the ports as the sockets they are, so `http://host` (80) and `https://host` (443) are no longer folded together (56cd566)
- Loading a page's fonts is no longer logged as a request that carried no device credential; that warning means what it says again (56cd566)
- A local door opened on loopback no longer hands out a link no phone can dial, refusing it by name the way the proxy channel already did (56cd566)
- A named proxy whose door could not bind now says why, instead of leaving a name applied to a door that is not there (56cd566)
- A channel that does not exist (400) and a door this machine does not have (409) use separate codes with separate words (56cd566)

- **Interface and the rest** — A browser tab is named by its page: the title is read once the load event says the document is done, dropped on a cross-document navigation, so tabs stop reading `https://…` (788e10c)
- Commit and push open a card rather than a dialog, so their names drop the ellipsis (969ec90)
- The minimize, maximize and close glyphs are drawn to one measure instead of three different sizes (25759cc)
- The window targets and the stop glyph take the bar's own measure, so the group stops sitting looser than its neighbours (fdf267a)
- A smoke run opens a home of its own, instead of losing the running Studio's data lock and raising that window on the way out (173c38c)
- The updater's nested paths hang off the publish host rather than the release prefix (c3bae8a)

## Removed

- Sign-in, cloud backup, the plugin market and the community are gone: with those surfaces gone the account had nothing left to do, and the pages, styles, payment QR images, link table and wording go with it (4a4c842)
- The "from anywhere" block is gone: this build has no sign-in to gate the relay on, and explaining a route nobody can take is worse than saying nothing (3c74271)
- The count on the view switch and the launcher's recent-files list are gone, and the styles and wording that drew them with them (712e863)

## Upgrade notes

- The phone side is a separate app to install (1.0.0). It reaches the kernel on this machine through its loopback proxy rather than a page opened in a browser (0b87f7e)
- A machine with both a network and a reverse proxy now opens both doors at once. A pairing code is issued per door, so switching doors means scanning again (c27905b)
- `127.0.0.1` is no longer offered as a share address: it is the door a proxy on this machine dials, and no phone can reach it (516d0ef)
- The workbench layout matches 2.58 again: the file tree is no longer draggable and the dock shows it in turn with the canvas rather than beside it (be94c64)
- The project list no longer remembers which projects were open; every cold launch starts folded (45e0f5d)
- Sign-in, cloud backup, the plugin market and the community are removed from this release; those surfaces and their data no longer appear (4a4c842)
