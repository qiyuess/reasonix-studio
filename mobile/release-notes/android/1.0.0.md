# 1.0.0

手机端应用的第一个正式版。手机只绘制界面，通过本机的回环代理连到这台电脑上的内核。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 变更

- **版本号进入 1.0.0**：此前手机端自己走 0.6.0 一类的号，与它配对的桌面端版本无关。从这一版起手机端随 Studio 一起发布、安装包与桌面端安装包一同提供下载，`versionCode` 从 28 进到 29（Android 不接受重复的 versionCode，即使名称变过）。
- **手机端并入 Studio 仓库**：源码、Android 工程与发布流程都落在这个仓库里，不再单独维护。

## 修复

- **回环代理同时携带两个 cookie jar 的凭据**：代理原有一个 WebView cookie jar 和一个内存 jar，请求只取前者。扫码进配对 WebView 的凭据落在 `CookieManager`，直接交给代理的凭据落在内存，两者都不是对方的超集；请求挑中空的那个时，内核收到的就是「从未配对」的答案。现在两者都带上。

## 说明

- 手机端从 debug 包切换到正式签名包的第一版，已装 debug 包的手机会因签名不同拒绝覆盖，需要卸载一次；配对 cookie 与 origin 会一起丢失，重新扫码即可。
