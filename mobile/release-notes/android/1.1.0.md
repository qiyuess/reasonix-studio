# 1.1.0

手机端随 Studio 2.71.1 一同发布。回合结束显示起止时间，归档改为可切换的范围，面板名称跟随电脑端的重命名，停止前先确认。

> 可以直接在「设置 → 偏好 → 关于」检查并安装这一版，配对信息、连接记录和本地设置都会保留。

## 新增

- **回合结束行显示起止时间**：与电脑端一致，形如 `2026-11-22 13:15:20 ~ 13:24:15`；同一天只说一次日期，跨天的回合两端都写全。重开会话后起止时间依然保留，不再只剩一个耗时数字。
- **归档是可切换的范围**：主界面两处标题行都能切换「进行中 / 归档」，归档视图只列还有内容的项目；项目归档标题行本身就是开关，标题里带着数量。
- **面板名称跟随电脑端的重命名**：通知栏、会话列表、聊天标题与需求卡统一读同一个名字。
- **停止按钮先确认再执行**：弹出确认单避免误触，正在结束的回合会自动关掉它。

## 修复

- **模型标签到位即显示模型名**，不再停留在「默认模型」；设置栏固定在自己的合成层，滚动中不再被页签层盖住。
- **启动窗口按页面配色显示**，图标不再带背板卡片。
- **通知栏标题用重命名后的名称**，不再读磁盘文件夹名。

## 移除

- **「完整界面」区块**与其整条链路：手机端只绘制自己的界面，不再内嵌桌面版页面。
- **「主题风格」设置行**：界面就是 Studio 的样子，无需再选。

## 说明

- `versionCode` 从 29 进到 30（Android 不接受重复的 versionCode，即使名称变过）。
