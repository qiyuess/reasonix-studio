# 1.2.0

配对页与「任务」入口的修复，语音输入整体移除。

> 覆盖安装即可，配对信息、连接记录与本地设置都会保留。

## 修复

- 扫码配对页保留自己的标题与返回栏，不再被内容盖住；状态栏跟随应用主题绘制 (90a1ce760)
- 自动归类的项目在手机上保留「任务」入口，项目行不再显示它的内部路径 (15f9239fb, 1c85943a4)
- 配对 cookie 按名字读取，不再依赖整段 cookie 的排列 (1c85943a4)

## 移除

- 语音输入、麦克风按钮与整套 speech 声明；手机只保留文字输入 (15f9239fb, c52602eac)

## 说明

- `versionCode` 从 33 进到 34（Android 不接受重复或倒退的 versionCode）。
- 从 1.1.2 及更早版本覆盖安装即可，无需卸载。
