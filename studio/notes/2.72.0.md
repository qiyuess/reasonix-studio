本版把工作台的自由尺寸行做成 Chrome 的设备工具条：iPhone、Pixel、Galaxy、iPad、Surface 与 Nest 显示器各有自己的视口、DPR、移动布局与 UA，可旋转、改数字或回到自适应。工作台在新建窗口不再空白，停靠浏览器与会话标签对齐；模型设置、电脑操作与安全边界一并修好。手机端升到 1.2.0。

## 新增

- 自由尺寸行提供 Chrome 设备工具条里的机型，每个带自己的视口、DPR、移动布局与 UA；旋转保留机型名，输入尺寸回到自适应 (fee13cc0e, c2bbbef75)
- 「修改…」只把光标放进两个尺寸字段，页面和 UA 在真正输入前保持不动 (572812fe9)
- 刷新模型会重新读取端点，并把显示名保存为别名 (61c01bcbd)
- 输入框记住最后一次选择的模型，作为下次的默认 (b98b7ef35)
- 设置页回到上次离开的分类；模型列表和单模型调参都能折叠收起 (1677a7bf7, 64581576c, 3fb8115b3)
- 电脑操作支持后台拖拽和驱动恢复提示，CUA 驱动固定到 0.59.0 (b43ff653c, 618c543a6)
- **手机端（1.2.0）** — 配对页保留自己的标题与返回栏，并跟随应用主题绘制 (90a1ce760)

## 修复

- 新建窗口打开工作台不再空白：只有分析视图会隐藏它；没有选择项目或会话时打开资源管理器，画布保持留白 (572812fe9)
- 有会话标签时，停靠的浏览器列不再在标签条下留一条空带 (44c2192a0)
- 设备行与页面不再各说各话：旧存档里没有机型的设备会回到自适应，面板大小重开后不再冒用某个机型名 (572812fe9)
- 冻结画面、停靠方格与全宽切换按钮回到各自的位置，不再被别的层裁掉 (551736697, d9c1a1b22, 6d2764680)
- 窄窗里的胶囊、浮层与弹出层留在窗口内，也不盖住相邻的层 (b1fa798de, 9d5267f22)
- 受限设备不能再访问文件与密钥相关路由；删除会话拒绝符号链接逃逸；限流信任代理写入的地址 (d0c333814, 4264f8277, 442bd7b30, 78629ef5d)
- 模型菜单选中即关闭；写好的视觉模型列表能被读到 (d18889d2d)
- **手机端（1.2.0）** — 自动归类的项目在手机上保留「任务」入口，内部路径不再混进项目行；配对 cookie 按名字读取 (15f9239fb, 1c85943a4)

## 移除

- 模型设置里的「隐藏共享前缀」开关移除，模型按路径最后一段显示 (efe5b4148)
- **手机端（1.2.0）** — 语音输入、麦克风按钮与整套 speech 声明移除 (15f9239fb, c52602eac)

This release gives the free-size row Chrome's Device toolbar: iPhone, Pixel, Galaxy, iPad, Surface and Nest displays, each with its own viewport, DPR, mobile layout and UA. A fresh workbench no longer opens blank, the docked browser lines up with the session tabs, and the phone app moves to 1.2.0.

## New

- The free-size row offers the devices Chrome's Device toolbar offers, each with its own viewport, DPR, mobile layout and UA; rotating keeps the device's name, and typing a side returns to Responsive (fee13cc0e, c2bbbef75)
- Edit only puts the cursor in the two size fields; the page and its UA stay put until a side is typed (572812fe9)
- Refreshing models re-reads the endpoint and keeps the display names as aliases (61c01bcbd)
- The composer remembers the last model picked and uses it as the next default (b98b7ef35)
- Settings returns to the page it was left on; model lists and per-model tuning fold behind their headings (1677a7bf7, 64581576c, 3fb8115b3)
- Computer use gains background drag and the driver's recovery hints, with the CUA driver pinned to 0.59.0 (b43ff653c, 618c543a6)
- **The phone app (1.2.0)** — The pairing sheet keeps its own header and back bar, painted with the app's theme (90a1ce760)

## Fixed

- A fresh window's workbench is drawn instead of blank; only the analysis view hides it, and Explorer with no project or session leaves the canvas empty (572812fe9)
- With session tabs on, the docked browser no longer leaves an empty band under the strip (44c2192a0)
- The device row and the page agree: a saved device without a recorded preset returns to Responsive, and Panel size no longer reopens under a device's name (572812fe9)
- The frozen picture, the docked squares and the full-workbench toggle answer their own places instead of being clipped by another layer (551736697, d9c1a1b22, 6d2764680)
- Pills, floating layers and popovers stay inside a narrow window and above their neighbour (b1fa798de, 9d5267f22)
- A forwarded device can no longer reach file and key routes; deleting a session refuses symlink escapes; the rate limiter trusts the proxy's stamp (d0c333814, 4264f8277, 442bd7b30, 78629ef5d)
- Picking a model closes its menu, and a written vision list is read (d18889d2d)
- **The phone app (1.2.0)** — The auto project keeps its 任务 entry on the phone, without its internal path in the row; the pairing cookie is read by name (15f9239fb, 1c85943a4)

## Removed

- The model setting's hide-shared-prefix switch is gone; a model reads by its last path segment (efe5b4148)
- **The phone app (1.2.0)** — Voice input, the microphone button and the speech declarations are gone (15f9239fb, c52602eac)
